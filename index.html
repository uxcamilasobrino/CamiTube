CamiTube

CamiTube shows only the channels listed in config.js. Your API key stays in your browser — it is never sent anywhere but Google.

Connect a YouTube API key

CamiTube reads video lists straight from YouTube's own API, using a free key that only you hold. Nothing is stored except in this browser.

  1. Open the Google Cloud Console and create (or pick) a project.
  2. Enable the YouTube Data API v3.
  3. Go to Credentials → Create credentials → API key.
  4. Paste it below.

The free quota (10,000 units/day) covers thousands of page loads for a channel list this size.
